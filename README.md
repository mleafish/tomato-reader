## 功能

- 📚 **书城个性化推荐** —— 按题材族群组织标签，再根据阅读记录、书架和搜索记录排出顺序；一页取三个标签交错，不会整屏都是同一个题材
- 🔍 **搜索与搜索记录** —— 支持书名、作者、关键词，最近搜过的词一键重搜、单条可删
- 📖 **书架** —— 每本书下面直接显示「已读 x/y 章」
- 🕘 **阅读记录** —— 读过什么一目了然，可左滑删除或整体清空
- 💬 **段评** —— 段尾气泡显示条数，点气泡或长按段落都能打开；三档可选：气泡 / 长按 / 隐藏
- 🖼️ **正文插图** —— 章节里的插图正常显示，点一下放大、可捏合缩放与拖动
- 💾 **全本下载** —— 断点续传，中途退出或被杀掉，下次进来接着下
- 📤 **数据导出与导入** —— 书架、阅读记录、阅读进度、搜索记录和阅读设置都能导出；换新版本时导入即可带走
- 👤 **账号登录** —— 登录番茄账号后同步书架与阅读进度
- 🎨 **阅读设置** —— 字号、行距、段间距、主题、字体、翻页效果、亮度、背景图
- 🌙 **自动阅读** —— 按设定速度自动翻页
